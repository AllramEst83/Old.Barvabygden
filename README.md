# Barvabygden Community Website

A static website for Barvabygden (Barva village), a charming community in Sweden located between Eskilstuna and Strängnäs. This site serves as the digital hub for local events, organizations, historical content, and community information.

🌐 **Live Site**: [barvabygden.se](https://barvabygden.se)  
🏛️ **Language**: Swedish (sv)  
👥 **Audience**: Local residents, visitors, and Swedish rural community enthusiasts

## 🏘️ About Barvabygden

Barvabygden is a historic Swedish village community rich in culture, tradition, and local heritage. Our website connects residents and visitors with:

- **Community Events** - Local festivals, markets, and cultural activities
- **Historical Archives** - Village history, museum collections, and newsletter archives
- **Local Services** - Businesses, organizations, and community resources
- **Sports & Recreation** - Barva IF sports club and recreational activities
- **Cultural Heritage** - Traditional crafts, local personalities, and historical documentation

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Framework**: Bootstrap 5.0.2 for responsive design
- **Typography**: Google Fonts (Cookie, Crimson Text, EB Garamond)
- **Build**: PowerShell deployment scripts
- **Compatibility**: Modern browsers with graceful degradation

## 🚀 Getting Started

### Prerequisites

- Modern web browser
- Web server (for local development)
- PowerShell (for deployment scripts)

### Local Development

1. Clone the repository
2. Open `index.html` in a web browser
3. For full functionality, serve through a local web server

### Deployment

Use the PowerShell deployment scripts in `assets/powershell/`

## 📝 Contributing

### Adding Events

Edit `assets/pages/events.html` with new event cards following the established structure.

### Adding Images

- Place in appropriate `assets/images/` subdirectories
- Use descriptive Swedish or English filenames
- Optimize for web performance

### Newsletter Updates

Add new newsletters to `assets/barva-news/[year]/` folders.
